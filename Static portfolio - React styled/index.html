02Featured · Distributed AI

Asynchronous Retrieval and LLM Processing System

Distributed RAG

A fault-tolerant document intelligence platform that moves parsing, chunking, embedding, and indexing outside the request path, then supports retrieval-only and LLM-assisted answer generation.

  • Kafka worker-based asynchronous ingestion
  • Dead-letter topics and deferred retries
  • 384-dimensional normalized MiniLM embeddings
  • Retrieval-only and LLM-assisted RAG modes
Explore the system＋

When a PDF or TXT file is uploaded, FastAPI creates both a document record and an ingestion job before publishing a Kafka event. A worker consumes that event, extracts and chunks the content, stores the chunks, produces normalized MiniLM embeddings, writes the vectors to FAISS, and updates the document and job state.

Workflow state is tracked across documents, ingestion jobs, chunks, index versions, and query logs. Failed ingestion events are moved to Kafka dead-letter topics, persisted as failures, and deferred so they can be retried after primary workloads.

The query side supports retrieval-only inspection and RAG generation through a provider-independent, OpenAI-compatible LLM service.

03Implemented core · expansion blueprint

Secure Permission-Driven CRM Platform

Nexora CRM

A secure full-stack CRM built with Next.js, TypeScript, CodeIgniter 4, and MySQL. Its implemented core combines customer and lead workflows with server-managed sessions, scoped RBAC, and audit history; its documented blueprint extends that foundation across the wider sales and operations lifecycle.

  • Feature-owned Next.js modules behind a secure BFF
  • Controller → service → model backend separation
  • Multi-role RBAC with own, team, department, and all scopes
  • Opaque sessions, HttpOnly cookies, UUID v7, and audit logging
Explore the complete blueprint＋

Implemented platform core

Customer and lead workflows, lead lifecycle actions, configurable roles and permissions, server-managed sessions, frontend permission visibility, backend authorization filters, and audit history operate across a normalized MySQL model.

Request architecture

Next.js App Router pages call browser-facing BFF route handlers. The BFF owns the HttpOnly session boundary and forwards server-side requests to versioned CodeIgniter REST endpoints. AuthFilter and PermissionFilter protect controllers before work reaches services, models, and MySQL.

Security model

Passwords use Argon2id. Opaque session tokens are retained in HttpOnly cookies while server-side session records support expiration and revocation. Permissions replace hard-coded role checks, and record access can be limited to own, team, department, or all permitted resources.

Expansion blueprint

The documented north-star extends the implemented foundation into employee administration, quotations, bookings, printing, invoices, payments, delivery, permission-aware reporting, session management, and broader operational audit trails. These modules are shown as blueprint scope rather than completed functionality.
